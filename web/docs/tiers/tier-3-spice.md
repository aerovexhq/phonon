# Tier 3: SPICE Circuit Electronics

Tier 3 provides industry-standard SPICE electronic circuit simulation powered by high-performance Modified Nodal Analysis (MNA).

## Solvers & Models
- **BSIM4 Unified Overdrive Model**: Industry-accurate MOSFET drain current, channel length modulation, and sub-threshold conduction.
- **Ward-Dutton Charge Conservation**: Physically consistent intrinsic terminal charge modeling avoiding false charge accumulation.
- **Gummel-Poon Bipolar Transistor (BJT)**: High-injection effects, base push-out, and thermal voltage tracking.
- **Newton-Raphson Non-Linear MNA**: Damped multi-dimensional Newton iteration with adaptive time-stepping (LTE truncation error control).
